# Code Review

When reviewing code:

1. Read the relevant code before making conclusions.
2. Identify correctness issues and potential bugs first.
3. Consider edge cases and failure paths.
4. Distinguish confirmed problems from suggestions.
5. Explain findings clearly and reference the relevant code.
6. Do not modify files unless the user explicitly asks for changes.
